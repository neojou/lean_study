## 1. 這份文件在講什麼

我們要在 Lean 裡自建一套邏輯，但必須先把兩件事分開（詳見 handoff）：

- **路線 A**：待在 Lean 自己的 CIC／`Prop` 裡，只是不用 `Classical`。那是建構式數學，不是本專案。
- **路線 B**：把 Lean 當**後設語言**，另外編碼一套**對象語言**、一套**推導關係**、一套**語意**。這才是「自建公理系統」。

本專案走 B。對象系統分兩階段：

| 階段 | 名稱 | 內容 |
|---|---|---|
| 第一 | **IPC** | 命題語言 + 直覺主義自然演繹 NJ |
| 第二 | **IQC** | 在 IPC 上加項、量詞，成為直覺主義一階邏輯 |

兩階段共用同一套哲學：不用排中律，規則用 Gentzen 的引入／消除，語意用 Kripke 強制。第一階段就要能證明兩件「aha」：

1. 析取性質：空脈絡下若 `⊢ φ ⋁ ψ`，則 `⊢ φ` 或 `⊢ ψ`。
2. 排中律不可證：一般原子 `p` 有 `⊬ p ⋁ ∼p`。

完備性、切割消除的 Hauptsatz、Gödel 不完備、模態、機率邏輯，都不在本規格的必做範圍。

## 2. 兩層語言

後設語言是 Lean 的相依類型論。對象語言是我們自己定義的公式。兩邊都有「且、或、若則、否」，**記號必須不同**，否則讀者會以為兩層是同一個。

| | 後設（Lean） | 對象（本系統） |
|---|---|---|
| 真 | `True`／該命題有證明項 | `⊤ᵢ` |
| 假 | `False` | `⟂` |
| 否定 | `¬` | `∼` |
| 合取 | `∧` | `⋀` |
| 析取 | `∨` | `⋁` |
| 蘊涵 | `→` | `⇒` |
| 可證 | 有一個型別為該 `Prop` 的項 | `Γ ⊢ φ` |
| 語意真 | （後設的真） | 某世界 `w ⊩ φ` |

判斷（judgment）只有一種主形式：

```
Γ ⊢ φ
```

讀作：在假設列 `Γ` 之下，對象公式 `φ` 可推導。`Γ` 是有限列，不是集合；重複假設可以出現。空列寫成 `⊢ φ`。

「`φ` 是定理」是後設說法，意思是存在一棵以 `⊢ φ` 為根的推導樹。不要把「Lean 能 `exact` 某個 `Prop`」跟「對象系統能 `⊢ φ`」混成一句話。

## 3. 直覺主義要什麼、不要什麼

### 3.1 BHK 解釋（證明是什麼）

直覺主義把「證明」當成構造，而不是「非假即真」的二值標籤。Brouwer–Heyting–Kolmogorov（BHK）的口語版：

- `φ ⋀ ψ` 的證明：一對證明，左邊證 `φ`、右邊證 `ψ`。
- `φ ⋁ ψ` 的證明：一個標籤 + 其中一邊的證明。你必須交出左邊或右邊。
- `φ ⇒ ψ` 的證明：一個方法，拿到 `φ` 的證明就能造出 `ψ` 的證明。
- `⟂` 沒有證明。
- `∼φ` 定義成 `φ ⇒ ⟂`：一個方法，拿到 `φ` 的證明就能造出荒謬。
- （一階）`∀x φ` 的證明：一個方法，給任意項 `t` 就給出 `φ[t/x]` 的證明。
- （一階）`∃x φ` 的證明：一個見證項 `t`，加上 `φ[t/x]` 的證明。

這直接解釋兩件後設事實：

- **析取性質**：空脈絡的析取證明必須已經選邊，所以可以抽出左邊或右邊的證明。
- **沒有排中律**：一般的 `p ⋁ ∼p` 並沒有構造——你既拿不出 `p` 的證明，也拿不出「`p` 會導致荒謬」的方法。古典邏輯把「還沒決定」也算真；直覺主義不承認這種真。

### 3.2 三層強度

```
極小邏輯  ⊂  直覺主義  ⊂  古典
(無 ⟂E)      (加 ⟂E)     (再加 LEM 或 RAA 或 DNE)
```

- **極小邏輯**：有引入／消除，但從荒謬推不出任意公式。
- **直覺主義（本系統）**：加上 ex falso `⟂E`：從 `Γ ⊢ ⟂` 可推 `Γ ⊢ φ`。這是 Heyting 的 IPC／IQC。
- **古典**：再加下列任一條（命題層上彼此可互推）：
  - 排中律 LEM：`⊢ φ ⋁ ∼φ`
  - 古典歸謬 RAA：若 `∼φ :: Γ ⊢ ⟂` 則 `Γ ⊢ φ`
  - 雙重否定消除 DNE：`⊢ ∼∼φ ⇒ φ`
  - Peirce：`⊢ ((φ ⇒ ψ) ⇒ φ) ⇒ φ`

務必分清兩種「歸謬」：

| 規則 | 前提 | 結論 | 本系統？ |
|---|---|---|---|
| 否定引入 `negI` | `φ :: Γ ⊢ ⟂` | `Γ ⊢ ∼φ` | 要（其實就是 `impI`） |
| 古典 RAA | `∼φ :: Γ ⊢ ⟂` | `Γ ⊢ φ` | **不要** |

直覺主義允許「假設 `φ` 推出矛盾，因此 `∼φ`」。它不允許「假設 `∼φ` 推出矛盾，因此 `φ`」——那等於從 `∼∼φ` 回到 `φ`。

## 4. 三種呈現，本專案選自然演繹

同一套直覺主義邏輯，歷史上至少有三種等價呈現：

| 呈現 | 判斷長什麼樣 | 「公理」是什麼 |
|---|---|---|
| Hilbert／Heyting | 只有 `⊢ φ`，假設靠蘊涵內化 | 一列公理圖式 + modus ponens |
| Gentzen **NJ**（自然演繹） | `Γ ⊢ φ` | 每個連詞一對引入／消除規則 |
| Gentzen **LJ**（sequent） | `Γ ⇒ Δ`，直覺主義限制 `Δ` 至多一個公式 | 左／右引入規則 + cut |

本專案的**公理架構本體是 NJ 的規則**，不是 Hilbert 公設列。理由：

1. 引入／消除與 BHK 一一對應：合取引入就是造對、蘊涵引入就是抽象出一個方法。
2. 在 Lean 裡，每條規則就是歸納謂詞的一個 constructor；對象證明是一棵項，後設定理是對這棵樹歸納。Hilbert 的「公理圖式 + 代換 + MP」也可以做，但證明項較不直觀，學習效益較差。
3. 我們仍在第 9 節列出 Hilbert／Heyting 公設，方便習慣「公理系統」的讀者對照。兩套等價，**實作只做 NJ**，避免兩個 `⊢` 並存。

所以：問「這套邏輯的公理是什麼？」——答案是下一節的語法建構子，加上第 6 節的 NJ 規則。沒有額外的非邏輯公理；這是純邏輯，還不是算術或集合論。

## 5. 命題語言（IPC 的語法）

### 5.1 原語

固定一類**命題變元**（原子）的集合 `α`。實作時 `α` 會是型別參數，第一版用 `String` 或 `ℕ` 即可。

公式 `φ, ψ, χ ∈ Formula(α)` 由下列子句歸納產生：

1. 若 `p ∈ α`，則原子 `⟪p⟫` 是公式。（文件裡常簡寫成 `p`。）
2. `⟂` 是公式（荒謬、假）。
3. 若 `φ, ψ` 是公式，則 `(φ ⋀ ψ)`、`(φ ⋁ ψ)`、`(φ ⇒ ψ)` 是公式。

沒有別的公式。特別是：

- **沒有**原語否定、原語真。
- **沒有**量詞（那是第 12 節）。
- **沒有**模態算子、機率算子。

### 5.2 定義連詞

```
∼φ   :=  φ ⇒ ⟂
⊤ᵢ   :=  ⟂ ⇒ ⟂
```

`⊤ᵢ` 的下標 i 提醒這是直覺主義的真，不是 Lean 的 `True`。任一脈絡都可以推出 `⊤ᵢ`（假設荒謬，再交還荒謬）。

雙重否定 `∼∼φ` 就是 `(φ ⇒ ⟂) ⇒ ⟂`。引入可證，消除不可證——這會是語意那一節的標準例子。

### 5.3 脈絡

脈絡 `Γ, Δ` 是公式的有限列。寫 `φ :: Γ` 表示左邊多一個假設。成員關係 `φ ∈ Γ` 是後設的 List 成員。

刻意**不**把脈絡當成集合：

- 交換、收縮可以當後設引理再證，不必一開始就用有限集。
- 重複假設（同一公式出現兩次）可以接受。
- 弱化有清楚的「在列前面加一個」版本，對應 Lean 的 `List` 操作。

## 6. NJ 推導規則（本系統的公理架構）

以下每條規則的**名稱就是之後 Lean constructor 的名字**。讀推論圖時，橫線上方是前提（已經有的推導），下方是結論。

### 6.1 結構規則

**假設（axiom / assumption）**

```
  φ ∈ Γ
 ────── ax
  Γ ⊢ φ
```

這是唯一「從天上掉下來」的規則：列裡有的假設可以直接用。它不是古典的非邏輯公理，只是「假設可用」。

**弱化（weakening）**

```
   Γ ⊢ φ
 ────────── weaken
  ψ :: Γ ⊢ φ
```

多一個用不到的假設，結論不變。也可以不當作原規則、改成對推導歸納的後設引理；本專案兩者都保留：原規則讓對象證明好寫，後設引理處理一次加一整列。

交換與收縮不當原規則。需要時在後設層證明：若 `Γ` 與 `Δ` 作為多重集相同，則 `Γ ⊢ φ` 當且僅當 `Δ ⊢ φ`（可後補，不阻第一階段）。

### 6.2 合取

```
  Γ ⊢ φ    Γ ⊢ ψ
 ──────────────── andI
    Γ ⊢ φ ⋀ ψ

    Γ ⊢ φ ⋀ ψ              Γ ⊢ φ ⋀ ψ
   ───────── andEL        ───────── andER
      Γ ⊢ φ                   Γ ⊢ ψ
```

引入造對；消除拆對。對應 BHK 的 pair / proj。

### 6.3 析取

```
     Γ ⊢ φ                    Γ ⊢ ψ
 ──────────── orIL       ──────────── orIR
   Γ ⊢ φ ⋁ ψ                Γ ⊢ φ ⋁ ψ

  Γ ⊢ φ ⋁ ψ    φ :: Γ ⊢ χ    ψ :: Γ ⊢ χ
 ───────────────────────────────────── orE
                 Γ ⊢ χ
```

引入必須選邊。消除是「分案」：知道析取，且每一邊都能推出同一個 `χ`，則不選邊也能得 `χ`。`orE` 的兩支假設各自把一邊加進脈絡，推完就丟掉——這不是古典的 `by_cases`（那是對 `φ ⋁ ∼φ` 分案）。

### 6.4 蘊涵

```
   φ :: Γ ⊢ ψ
  ────────── impI
   Γ ⊢ φ ⇒ ψ

  Γ ⊢ φ ⇒ ψ    Γ ⊢ φ
 ────────────────── impE
        Γ ⊢ ψ
```

引入是演繹定理本身：在假設 `φ` 下證出 `ψ`，就得到蘊涵。消除是 modus ponens。這對規則幾乎就是 BHK 對「方法」的描述。

### 6.5 荒謬（直覺主義的那一條）

```
  Γ ⊢ ⟂
 ────── falsumE
  Γ ⊢ φ
```

ex falso quodlibet：從矛盾可推出任意公式。沒有這條是極小邏輯；有這條、但沒有第 8 節的古典規則，就是直覺主義。

沒有 `falsumI`。唯一製造 `⟂` 的方式是已經有 `φ` 又有 `∼φ`（見下一節的 `negE`），或假設列裡本來就有 `⟂`。

## 7. 導出規則（不是原語，但常用）

這些規則必須能用第 6 節證出來。實作時它們是 Lean 的 `def` / `theorem`，不是 `inductive` 的新 constructor。

### 7.1 否定

因為 `∼φ := φ ⇒ ⟂`：

```
   φ :: Γ ⊢ ⟂                 Γ ⊢ ∼φ    Γ ⊢ φ
  ────────── negI            ──────────────── negE
    Γ ⊢ ∼φ                         Γ ⊢ ⟂
```

`negI` 就是 `impI`；`negE` 就是 `impE`。不要另立「否定原語」，否則還得證它跟 `φ ⇒ ⟂` 等價，白做工。

### 7.2 真

```
 ────── verumI
  Γ ⊢ ⊤ᵢ
```

證法：`⊤ᵢ = ⟂ ⇒ ⟂`。在 `⟂ :: Γ` 用 `ax` 得 `⟂`，再 `impI`。

### 7.3 切割（cut）

```
  Γ ⊢ φ    φ :: Γ ⊢ ψ
 ──────────────────── cut
        Γ ⊢ ψ
```

NJ 裡 cut 可容許，而且證明很短：對第二棵樹做 `impI` 得 `Γ ⊢ φ ⇒ ψ`，再與第一棵做 `impE`。若將來改成 sequent 系統，cut 可容許性會變成大定理（Hauptsatz）；本專案不走那條路。

### 7.4 列上的弱化

```
  Γ ⊢ φ
 ────────── weaken_list   （Δ 是任意有限列）
  Δ ++ Γ ⊢ φ
```

對 `Δ` 的長度歸納，每步用一次 `weaken`。

### 7.5 幾個應該會證出來的對象定理

以下都是**對象**定理（空脈絡或帶參數公式）：

| 陳述 | 備註 |
|---|---|
| `⊢ φ ⇒ φ` | 恆等；`ax` + `impI` |
| `⊢ (φ ⋀ ψ) ⇒ (ψ ⋀ φ)` | 合取交換 |
| `⊢ (φ ⋁ ψ) ⇒ (ψ ⋁ φ)` | 析取交換 |
| `⊢ φ ⇒ ∼∼φ` | 雙重否定**引入** |
| `⊢ φ ⇒ (ψ ⇒ φ)` | Hilbert 的 K 組合子 |
| `⊢ ⟂ ⇒ φ` | 其實就是 `falsumE` 的蘊涵化 |

以下**不要**當成待證定理（它們在 IPC 裡不可證）：

| 陳述 | 為什麼卡住 |
|---|---|
| `⊢ φ ⋁ ∼φ` | LEM |
| `⊢ ∼∼φ ⇒ φ` | DNE |
| `⊢ ((φ ⇒ ψ) ⇒ φ) ⇒ φ` | Peirce |
| `⊢ ∼(φ ⋀ ψ) ⇒ (∼φ ⋁ ∼ψ)` | De Morgan 的古典方向 |

最後一條很適合作練習：直覺主義有 `⊢ (∼φ ⋁ ∼ψ) ⇒ ∼(φ ⋀ ψ)`，反方向沒有。試著組 NJ 樹會在 `orI` 那步發現必須選邊，但你不知道該選 `∼φ` 還是 `∼ψ`。

## 8. 明確排除的古典原則

本系統**沒有**下列規則。加入任何一條（命題層）都會得到古典命題邏輯 CPC。

**排中律 LEM**

```
 ─────────── lem     （不要）
  Γ ⊢ φ ⋁ ∼φ
```

**古典歸謬 RAA**

```
  ∼φ :: Γ ⊢ ⟂
 ──────────── raa     （不要）
    Γ ⊢ φ
```

**雙重否定消除 DNE**

```
  Γ ⊢ ∼∼φ
 ───────── dne        （不要）
   Γ ⊢ φ
```

**Peirce**

```
 ──────────────────────── peirce   （不要）
  Γ ⊢ ((φ ⇒ ψ) ⇒ φ) ⇒ φ
```

若以後要做對照，另開模組（例如 `Mylogic.Classical`）把其中一條加進去，再證它推出另外幾條。不要在預設的 `Deduction` 裡開後門。

## 9. Hilbert／Heyting 公設對照

習慣「公理系統」的讀法：IPC 可以由下列公理圖式 + 唯一規則 MP 生成。所有公式、所有變元實例都是公理。否定仍視為定義。

**蘊涵（組合子 K、S）**

1. `φ ⇒ (ψ ⇒ φ)`
2. `(φ ⇒ (ψ ⇒ χ)) ⇒ ((φ ⇒ ψ) ⇒ (φ ⇒ χ))`

**合取**

3. `(φ ⋀ ψ) ⇒ φ`
4. `(φ ⋀ ψ) ⇒ ψ`
5. `φ ⇒ (ψ ⇒ (φ ⋀ ψ))`

**析取**

6. `φ ⇒ (φ ⋁ ψ)`
7. `ψ ⇒ (φ ⋁ ψ)`
8. `(φ ⇒ χ) ⇒ ((ψ ⇒ χ) ⇒ ((φ ⋁ ψ) ⇒ χ))`

**荒謬**

9. `⟂ ⇒ φ`

**規則**

- MP：從 `φ ⇒ ψ` 與 `φ` 得 `ψ`。

這九條在 NJ 裡都可證（大多數是「引入規則的蘊涵化」）。反過來，NJ 的每一條規則也可以在 Hilbert 系統裡模擬（通常要對推導長度歸納，並用演繹定理）。因此：

> 本專案的公理架構**等價於**上述 Heyting 公設；呈現形式選 NJ。

古典命題邏輯 = 上述公設 + LEM（或 DNE，或 Peirce）。極小邏輯 = 拿掉公設 9。

Hilbert 系統**不當本專案主線實作**。列在這裡只為了回答「公設是哪些」。

## 10. Kripke 語意（命題）

語法說「哪些推導合法」；語意說「公式在什麼情況下算真」。直覺主義不用二值賦值當主語意——經典的 `0/1` 會讓 LEM 永真。標準選擇是 Kripke 框架：真值可以「以後才決定」。

### 10.1 框架與賦值

一個**命題 Kripke 框架**是：

- 一組世界 `W`；
- `W` 上的前序 `≤`（自反、傳遞；不要求反對稱）；
- 原子賦值 `V`：對每個世界 `w`、每個原子 `p`，給定是否 `V(w, p)`。

賦值必須**持續**（persistent / hereditary）：

```
若 w ≤ w' 且 V(w, p)，則 V(w', p)。
```

直觀：世界沿著 `≤` 往「資訊更多」的方向走。原子一旦為真就不再撤回。尚未決定的原子可以在後繼世界變成真。

### 10.2 強制關係 `⊩`

對公式結構歸納定義 `w ⊩ φ`（`w` 強制 `φ`）：

| 公式 | `w ⊩ …` 的條件 |
|---|---|
| 原子 `p` | `V(w, p)` |
| `⟂` | 永不成立（`w ⊮ ⟂`） |
| `φ ⋀ ψ` | `w ⊩ φ` 且 `w ⊩ ψ` |
| `φ ⋁ ψ` | `w ⊩ φ` 或 `w ⊩ ψ` |
| `φ ⇒ ψ` | 對所有 `w' ≥ w`：若 `w' ⊩ φ` 則 `w' ⊩ ψ` |
| `∼φ`（定義） | 對所有 `w' ≥ w`：`w' ⊮ φ` |

蘊涵的子句是直覺主義的核心：`φ ⇒ ψ` 在 `w` 為真，意思是**以後任何更有資訊的世界**，只要 `φ` 成立，`ψ` 也成立。現在還看不到 `φ` 沒關係。

**單調性引理**（對公式歸納）：若 `w ⊩ φ` 且 `w ≤ w'`，則 `w' ⊩ φ`。原子靠持續賦值；蘊涵靠 `≤` 的傳遞。

寫 `w ⊩ Γ` 表示 `Γ` 中每個公式都被 `w` 強制。

### 10.3 健全性

> **健全性。** 若 `Γ ⊢ φ`，則對任意框架、任意世界 `w`：只要 `w ⊩ Γ`，就有 `w ⊩ φ`。

證明對推導樹歸納：每條 NJ 規則在強制關係下都成立。這是後設定理，而且可以走建構式證明——不需要排中律。

推論：若存在某個框架的某個世界 `w` 使得 `w ⊩ Γ` 但 `w ⊮ φ`，則 `Γ ⊬ φ`。這是「證不可證」的引擎。

### 10.4 完備性（只陳述，第一階段不證）

> **完備性（命題 IPC）。** 若在所有框架的所有世界上，`Γ` 被強制則 `φ` 被強制，則 `Γ ⊢ φ`。

這是真的，但證明較長（典型做法：典範模型，或有限模型性 + 過濾）。第一階段**不**把它當目標。需要不可證時，做一個具體的有限反模型即可。若將來要證完備性且後設非古典不可，必須獨立標成「後設古典、對象直覺主義」。

## 11. 反模型：LEM 與 DNE 不可證

### 11.1 兩世界框架

世界：`w₀`、`w₁`。前序：`w₀ ≤ w₀`、`w₁ ≤ w₁`、`w₀ ≤ w₁`（`w₁ ≰ w₀`）。

原子 `p` 的賦值：只在 `w₁` 為真。持續性成立。

```
        w₁   ⊩ p
        ↑
        w₀   ⊮ p
```

### 11.2 排中律失敗

在 `w₀`：

- `w₀ ⊮ p`：賦值如此。
- `w₀ ⊮ ∼p`：因為存在後繼 `w₁ ≥ w₀` 且 `w₁ ⊩ p`，所以並非「所有未來都看不到 `p`」。
- 因此 `w₀ ⊮ p ⋁ ∼p`。

空脈絡在每個世界都被強制（沒有假設）。由健全性：`⊬ p ⋁ ∼p`。

這對**一般原子**成立。某些具體公式仍然可以有 `⊢ φ ⋁ ∼φ`（例如 `φ` 已經可證，或 `φ` 是 `⊤ᵢ`）。不可證的是「任意公式的排中律」這條圖式。

### 11.3 雙重否定消除失敗

同一框架、同一個 `p`。先看 `∼∼p = (p ⇒ ⟂) ⇒ ⟂`。

`w ⊩ ∼∼p` 當且僅當每個 `w' ≥ w` 都有 `w' ⊮ ∼p`，也就是每個未來都能再走到一個強制 `p` 的世界。

- 從 `w₀`、`w₁` 都能走到 `w₁`，而 `w₁ ⊩ p`，故 `w₀ ⊩ ∼∼p`。
- 但 `w₀ ⊮ p`。
- 因此 `w₀ ⊮ ∼∼p ⇒ p`。

由健全性：`⊬ ∼∼p ⇒ p`。

對照第 7.5 節：`⊢ p ⇒ ∼∼p` 在 NJ 裡很好證。引入與消除不對稱，是直覺主義的招牌。

## 12. 後設性質（命題階段要對誰負責）

以下都是關於 NJ 的後設定理，不是對象規則。

| 性質 | 陳述 | 第一階段？ |
|---|---|---|
| 健全性 | `Γ ⊢ φ` ⇒ 所有強制 Γ 的世界都強制 φ | 要 |
| LEM 不可證 | `⊬ p ⋁ ∼p`（一般原子） | 要 |
| DNE 不可證 | `⊬ ∼∼p ⇒ p` | 建議 |
| 析取性質 | 若 `⊢ φ ⋁ ψ` 則 `⊢ φ` 或 `⊢ ψ` | 要（可稍後於反模型） |
| 弱化／換脈絡 | 列操作不改變可推導性 | 要（弱版即可） |
| cut 可容許 | 第 7.3 節 | 要（NJ 裡很短） |
| 演繹定理 | `Γ ⊢ φ ⇒ ψ` ⇔ `φ :: Γ ⊢ ψ` | 幾乎是 `impI`／`impE` |
| 完備性 | 第 10.4 節 | 不要當第一階段 |
| 有限模型性 | IPC 對有限 Kripke 框架完備 | 不要當第一階段 |

析取性質必須**建構地**證：給出一棵 `⊢ φ` 或一棵 `⊢ ψ` 的推導。標準證明是對空脈絡推導做歸納，並維持「推導沒有未消掉的開放假設」這類不變量；細節留給實作。不要用後設 LEM 說「不是左就是右」。

直覺主義還有**存在性質**（一階才有意義），見第 15 節。

## 13. 一階語言（IQC 的語法）

命題階段過關之後，才把對象語言升級成一階。本節是規格；實作排在課綱 Phase 8。**不要把量詞直接加進命題的 `Formula`**，否則前面的歸納證明會全部多兩個 case、還可能改壞記號。

### 13.1 語言簽名

一個一階語言包含：

- 可數的**變元**（具名時寫 `x, y, z`；de Bruijn 時是自然數指標）；
- 函數符號，各帶元數 `n ≥ 0`（0 元函數就是常數）；
- 謂詞符號，各帶元數 `n ≥ 0`（0 元謂詞就是命題原子）。

第一版可以極小：只有變元、沒有函數符號、只有一個一元謂詞。簽名愈小，代入引理愈短。

### 13.2 項

項 `t, s` 歸納定義：

1. 每個變元是項；
2. 若 `f` 是 n 元函數、`t₁, …, tₙ` 是項，則 `f(t₁, …, tₙ)` 是項。

沒有函數符號時，項就是變元。這對第一版 IQC 夠用。

### 13.3 公式

在命題連詞之上加：

1. 若 `P` 是 n 元謂詞、`t₁, …, tₙ` 是項，則 `P(t₁, …, tₙ)` 是公式（原子）；
2. `⟂`、`φ ⋀ ψ`、`φ ⋁ ψ`、`φ ⇒ ψ` 同命題；
3. 若 `φ` 是公式、`x` 是變元，則 `∀x φ`、`∃x φ` 是公式。

`∼`、`⊤ᵢ` 仍為定義。等號不當原語（見第 16 節）。

### 13.4 自由變元與代入（這是 FOL 真正難的地方）

`FV(t)`、`FV(φ)` 是自由變元集合。量詞會綁定：`FV(∀x φ) = FV(φ) \ {x}`。

代入 `φ[t/x]` 必須是**捕捉迴避**的：不能把 `t` 裡的自由變元送進量詞作用域裡改綁。經典反例：

```
φ      =  ∃y. R(x, y)
t      =  y
錯誤代入  ∃y. R(y, y)     ← y 被捕捉，意思整個變了
正確代入  ∃z. R(y, z)     ← 先換約束變元
```

在證明助手裡這件事有兩條路：

| 策略 | 優點 | 代價 |
|---|---|---|
| 具名變元 | 公式好讀，對齊教科書 | 換名、新鮮變元、代入交換引理很長 |
| de Bruijn 指標 | 代入是結構遞迴，沒有捕捉 | 公式難讀，要定義 shift／lift |

本專案**傾向 de Bruijn 當實作主線**（見 `AGENTS.md`）。規格書繼續用具名變元寫規則，因為那是邏輯學的標準口語。

側條件裡會出現「`x` 不在 `Γ` 中自由」，寫成 `x ∉ FV(Γ)`，其中 `FV(Γ)` 是列中所有公式自由變元的聯集。

## 14. 一階 NJ（量詞規則）

命題規則全部原樣保留。新增四條。名稱預留給 Lean constructor。

### 14.1 全稱

```
  Γ ⊢ φ          x ∉ FV(Γ)
 ───────────────────────── forallI
        Γ ⊢ ∀x φ

        Γ ⊢ ∀x φ
 ───────────────────────── forallE
        Γ ⊢ φ[t/x]
```

`forallI` 的側條件是 **eigenvariable（特徵變元）條件**：`x` 在假設裡不能自由出現。否則你會從假設 `R(x)` 推出 `∀x R(x)`，那是錯的。

直觀：`x` 在推導中是「任意但固定」的。它不能已經被脈絡釘成某個特定對象。

### 14.2 存在

```
      Γ ⊢ φ[t/x]
 ───────────────────────── existsI
        Γ ⊢ ∃x φ

  Γ ⊢ ∃x φ     φ :: Γ ⊢ ψ      x ∉ FV(Γ) ∪ FV(ψ)
 ────────────────────────────────────────────── existsE
                      Γ ⊢ ψ
```

`existsI` 要交出見證項 `t`。`existsE` 的 eigenvariable 條件更嚴：消除用的那個 `x` 不能在結論 `ψ` 裡自由出現，也不能在其餘假設裡自由出現。否則你會把見證漏到結論裡，變成「有某個 `x` 滿足 `φ`，因此這個 `x` 滿足 `ψ`」——但結論不該還依賴那個匿名見證。

### 14.3 與 BHK 的對應

- `forallI`／`forallE`：方法「給任意項就給證明」vs 對某個項取值。
- `existsI`／`existsE`：交出見證 vs 使用見證但不讓它逃出作用域。

古典一階邏輯會再加 LEM（或等價物）。有了 LEM，`∼∀x φ` 可以推出 `∃x ∼φ`；直覺主義沒有這條。對照：

| 方向 | IQC？ |
|---|---|
| `⊢ (∀x φ) ⇒ ∼∃x ∼φ` | 可證 |
| `⊢ (∃x φ) ⇒ ∼∀x ∼φ` | 可證 |
| `⊢ (∼∃x ∼φ) ⇒ ∀x φ` | 不可證（需 DNE／LEM） |
| `⊢ (∼∀x ∼φ) ⇒ ∃x φ` | 不可證 |

第一版對象練習優先做可證的那兩條，以及顯然的 `⊢ (∀x φ) ⇒ φ[t/x]`、`⊢ φ[t/x] ⇒ ∃x φ`。

## 15. 一階 Kripke 素描

命題框架再加論域。

每個世界 `w` 帶一個非空論域 `D(w)`。前序要**擴張論域**：若 `w ≤ w'` 則有包含 `D(w) ⊆ D(w')`（或等價的遷移映射）。函數符號、謂詞符號的解釋要與這些包含相容（後繼世界不能改寫已經出現的元素上的函數值；謂詞對已經為真的原子要持續）。

強制的新子句（把自由變元當成「當前論域裡的指派」來讀）：

```
w ⊩ ∀x φ    ⇔    對所有 w' ≥ w、所有 a ∈ D(w')，都有 w' ⊩ φ[a/x]

w ⊩ ∃x φ    ⇔    存在 a ∈ D(w)，使得 w ⊩ φ[a/x]
```

注意不對稱：

- 全稱必須對**未來更大論域**裡的新元素也成立（以後才出現的東西現在的全稱也管得到）。
- 存在只要求**當前**論域有見證（不能拿一個以後才出現的元素當現在的見證）。

沒有擴張論域的話，強制的單調性會壞掉。

**存在性質**（IQC、空脈絡、通常還要假設語言裡有見證項或允許開放項）：若 `⊢ ∃x φ`，則存在項 `t` 使得 `⊢ φ[t/x]`。這是析取性質的一階兄弟，同樣來自 BHK。第一版實作允許只做語法 + 推導、語意當進階。

健全性陳述與命題相同：推導出來的公式在所有（帶指派的）世界上被強制。LEM 的兩世界反模型仍然可用——量詞還沒出場時，命題反模型就是一階反模型的特例。

## 16. 等號（可選，不當第二階段必做）

若要加等號 `t ≈ s`（對象等號，避免跟 Lean 的 `=` 混），典型直覺主義規則是：

```
 ────────── eqRefl
  Γ ⊢ t ≈ t

  Γ ⊢ t ≈ s     Γ ⊢ φ[t/x]
 ──────────────────────── eqSubst
        Γ ⊢ φ[s/x]
```

函數與謂詞的合同可以由代入規則推出。等號的 Kripke 解釋是：每個世界的論域上有一個等價關係，隨世界擴張而只增不減，且解釋要尊重它。

這會讓代入與健全性再長一截。**第一、二階段不做等號。** 需要時當第三階段。

## 17. 階段邊界：刻意不做的事

規格允許以後討論，但**現在不要做**：

- 把對象公式嵌進 Lean 的 `Prop`，再證「對象 LEM ⇔ Lean 的 `Classical.em`」當主線——兩層會黏在一起。
- 在預設 NJ 裡加入 `Classical.em` 的翻譯。
- 完整的 cut 消除 Hauptsatz（NJ 的 cut 可容許已經夠短；sequent 版是另一個專案）。
- Gödel 不完備、算術語言、可表徵性。
- 模態 `□` / `◇`（Kripke 框架會複用，但等 IPC 後設過關）。
- 機率算子 `P≥r`（技術上像模態；語意不要一開始就引 Mathlib 測度論）。
- 超直覺主義中間邏輯、線性邏輯、相依類型當對象。
- 一階完備性（對 Kripke 或 Heyting 代數）。

本系統也**不是** Lean 的 kernel。底層永遠是 CIC。我們在 CIC **上面**研究 IPC／IQC。
